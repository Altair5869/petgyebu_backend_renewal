# 요구사항 및 기능명세서: Petgyebu MVP

- 기준일: 2026-09-25
- 기준 문서: `01-prd.md`
- 기능 ID는 새 MVP에서만 사용하는 `F-M01`~`F-M06`이다. 과거 ID는 `04-review-log.md`의 이력으로만 남긴다.

## 공통 계약

- 인증된 API는 Bearer 액세스 토큰을 사용한다. 소셜 공급자는 `KAKAO`, `APPLE`이다.
- 금액은 원화 정수, 지출 금액과 예산은 1 이상이다. 지출 날짜는 `YYYY-MM-DD`, 월은 `YYYY-MM`이다. 서버의 월 경계는 `Asia/Seoul`이다.
- 카테고리는 `FOOD`, `CAFE`, `TRANSPORT`, `SHOPPING`, `HEALTH`, `LIVING`, `OTHER` 중 하나이며 사용자가 직접 선택한다.
- 요청한 사용자가 소유하지 않은 지출·예산은 조회하거나 변경할 수 없다. 해당 자원은 404로 응답한다. 형식·범위 오류는 400, 미인증은 401이다.
- 지출 수정·삭제와 예산 변경 뒤의 조회값은 현재 DB 상태에서 다시 계산한다. 별도 통계·상태 저장 테이블은 없다.

## F-M01 계정

| 항목 | 요구사항 |
|---|---|
| 로그인 | 카카오·애플 공급자의 인가 코드를 서버가 검증하고 `(provider, provider_user_id)`로 계정을 찾거나 생성한다. 이메일은 식별자로 사용하지 않는다. 성공 시 액세스 토큰을 발급한다. |
| 내 정보 | 사용자 ID, 공급자, 선택한 반려동물 종류를 반환한다. |
| 탈퇴 | 명시적 확인 후 계정을 삭제한다. 종속 지출·예산도 삭제한다. 각 인증 요청에서 사용자 존재를 확인하여 탈퇴 후 남은 토큰을 거부한다. |
| 제외 | 비밀번호 로그인, 계정 통합, 리프레시 토큰·세션 저장소, 로그아웃 API, 동의 이력 테이블은 MVP 범위 밖이다. 서비스 출시 전 필요한 법적 동의 문안과 앱 동의 화면은 별도로 준비한다. |

## F-M02 반려동물 선택과 성장

| 항목 | 요구사항 |
|---|---|
| 선택 | 사용자는 `CAT` 또는 `DOG` 한 마리를 선택하고 나중에 종류를 바꿀 수 있다. 선택 전 홈은 선택 안내를 반환한다. |
| 성장 | 현재 사용자의 전체 지출 건수 `n`을 기반으로 PRD의 레벨·진행도를 계산한다. 종류 변경은 기록 수를 지우지 않는다. |
| 상태 | 예산 사용률 구간으로 `NO_BUDGET`, `STABLE`, `CAUTION`, `OVER_BUDGET`을 계산한다. 월마다 독립적으로 계산한다. |

## F-M03 수동 지출

| 항목 | 요구사항 |
|---|---|
| 생성 | 금액, 날짜, 카테고리 필수. 메모는 선택이며 최대 200자. 지출 날짜는 미래 1년을 초과할 수 없다. |
| 조회 | 지정 월의 지출을 날짜 내림차순, ID 내림차순으로 반환한다. 비어 있으면 빈 목록이다. |
| 수정·삭제 | 본인 지출만 수정·삭제한다. 수정은 전체 필드 교체가 아니라 전달된 필드만 변경한다. 삭제한 지출은 통계에서 빠진다. |
| 중복 | 수동 입력은 동일 금액·날짜·카테고리가 실제로 여러 건일 수 있으므로 중복 방지 UNIQUE를 두지 않는다. |

## F-M04 월 예산

| 항목 | 요구사항 |
|---|---|
| 설정 | 사용자와 월마다 목표 금액 하나. 같은 월에 다시 PUT하면 금액을 교체한다. 과거·현재·미래 월을 설정할 수 있다. |
| 조회 | 예산이 없으면 `budget: null`로 응답한다. 지출 합계와 사용률·잔여/초과 금액은 예산이 있을 때 계산한다. |
| 경계 | `month`는 해당 월 1일로 저장한다. 월 전환 배치나 이전 예산 자동 복사는 없다. |

## F-M05 월별 통계

해당 월 지출 총액, 건수, 고정 카테고리별 합계·건수·비중을 반환한다. 지출이 없으면 총액 0, 건수 0, 카테고리 배열은 빈 배열이다. 비중은 `카테고리 합계 / 월 총액 × 100`을 소수 첫째 자리로 표시한다. 월 총액 0이면 비중 계산을 하지 않는다. 날짜 이동·수정·삭제는 이전 월과 새 월에 즉시 반영된다.

## F-M06 홈 요약

선택한 월의 총지출, 예산 금액 또는 `null`, 사용률 또는 `null`, 남은 금액 또는 초과 금액, 반려동물 종류, 상태, 성장 레벨·진행도를 한 번에 반환한다. `NO_BUDGET`은 경고가 아니라 설정 안내로 표현한다. 캐릭터 상태 문구는 앱에서 상태 코드에 맞춰 표시하며 서버는 상태 코드를 반환한다.

## 인수 기준

1. 사용자는 지출 하나를 저장하고 같은 월 목록·통계·홈에서 같은 금액을 본다.
2. 지출 날짜를 다른 월로 바꾸거나 삭제하면 양쪽 월의 합계와 상태가 다시 계산된다.
3. 70%·100% 경계, 예산 없음, 지출 없음이 정의대로 표시된다.
4. 다른 사용자의 ID로 조회·수정·삭제를 시도해도 데이터가 노출되지 않는다.
5. 계정 삭제 후 지출과 예산이 남지 않고 기존 토큰도 인증에 실패한다.
