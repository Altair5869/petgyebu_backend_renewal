# 과거 검토 기록 안내

- 상태: **개발 기준에서 제외**
- 현재 기준: [리뉴얼 개발 기준](00-renewal-development-guide.md), [PRD](01-prd.md), [기능명세](02-requirements-features.md), [유저플로우](03-user-flow.md)

이 번호는 기존 문서 링크가 깨지지 않도록 남겨둔다. 리뉴얼 이전의 계좌 연동, 자동 수집, 보상, 옛 펫 상태와 플랫폼 검토는 현재 MVP 개발에 적용하지 않는다. 현재 기능의 요구사항이나 완료 여부를 판단할 때 이 기록을 읽을 필요가 없다.

필요할 때만 [이전 검토 기록 원본](archive/04-review-log-legacy.md)을 확인한다. 이 보관본은 최종 개발 문서 다운로드 묶음에서 제외한다.
