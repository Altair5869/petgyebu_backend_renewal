## 외부 준비

소셜 공급자 설정과 이용약관·개인정보처리방침 문안이 출시 전 필요하다. Cloud Run·Cloud SQL 준비는 배포 시 필요하다. CODEF, Redis, 금융결제원 또는 푸시 설정은 이 백로그의 차단 요소가 아니다.

## 제외된 과거 작업

계좌·자동 거래·이체·환불 연결·자동 분류·거래 이력·임계값 설정·푸시·보상·상점·아이템·배치는 새 MVP 작업으로 이월하지 않는다. 과거 작업의 완료 사실은 역사적 기록으로 보존한다.
